What this page is
›

This page is the demo. There is no cloud host in front of it — it runs on the machine under my desk, in two containers, and reaches you through a tunnel.

My CV splits skills into Skilled and Beginner. So does this stack. Every hop below carries the same two labels, and the ones I had never run before are marked as such. Pick a hop to see what it does and the config that does it.

The only way in. This machine has no public IP and no port open to the internet — HAProxy binds to loopback and the tunnel dials out to Cloudflare.

# loadbalancer/haproxy.cfg.template
bind 127.0.0.1:${LB_PORT}

If the tunnel drops, the site is gone. Nothing else is holding it up. That is the trade I made on purpose.

The whole public surface. Rate limiting, client checks and routing all happen here, before a request reaches any application.

Three separate rate limits

http-request deny deny_status 429 if { sc_http_req_rate(0,st_site) gt 300 }
http-request deny deny_status 429 if is_api { sc_http_req_rate(1,st_api) gt 20 }
http-request deny deny_status 429 if is_api { sc_http_err_rate(1,st_api) gt 20 }

The last one is the useful one. Somebody guessing access tokens collects 401s and gets shut out on the error counter long before they reach the request limit.

Sec-Fetch-Site is the strongest check: every current browser sends it, and page JavaScript is forbidden from setting it. This filters, it does not authenticate — the access token is what gates entry.

Also here

  • every request gets a uuid, logged and passed on as X-Unique-ID
  • the session token is cut out of the path before anything is written to a log
  • stats page and 423 Prometheus metrics on a second frontend, loopback only
  • the config is a template — envsubst, then haproxy -c, so a bad value stops the container instead of shipping a broken edge

Serves this page and answers the chat, in one process. It is also the only thing allowed to talk to the model. It holds the sessions and the refusals — the persona asks the model to behave, the backend does not depend on it.

There used to be an nginx container in front of the files. It served four static files and nothing else, so it went away: express.static does the same job and the stack lost a container and a config template.

GET  /?chat_bot_token=<token>        widget renders
POST /api/session {chat_bot_token}   constant-time compare
                  → session = <expiry>.<nonce>.<HMAC>
POST /api/chat/<session>             verify HMAC + expiry

Every request is stateless. Conversation history never goes to the model, so nothing said earlier can steer a later answer. Answers are cut after four sentences.
